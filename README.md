## 文件夹架构

SystemicRisk项目文件框架包括：

主要文件夹：

- Collection：收集、记录临时笔记，后续待整理；
- Analyse：分析文献、分析研究思路；
- Notes：存放项目相关重要笔记；
- data：存放规则化小规模数据、存放实验数据；
- Models：建模；
- code：存放代码；
- Reference：存放参考资料；
- Reports：存放毕业论文、工作总结、报告、其它论文等；
- Resources：存放资源、资源链接；
- Subjects：存放项目相关学科知识；


次要文件夹：
- attachment：存放附件；
- Management：管理项目；
