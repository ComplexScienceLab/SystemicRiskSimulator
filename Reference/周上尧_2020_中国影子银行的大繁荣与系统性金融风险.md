# 研究背景

## 国际背景

金融危机爆发之前，美国在 2004 年至 2007 年期间经历了一段影子银行规模迅猛增长的时期；

期间，影子银行负债规模从 9 万亿美元上升至 15 万亿左右季度平均増速为 5.6%，而传统商业银行负债的平均增速仅为影子银行的一半；

影子银行规模的快速增长以及杠杄的不断上升加重了金融市场的脆弱程度；

影子银行间批发资金市场（wholesale market）的崩溃最终导致了金融危机的爆发（Gertler& Gilchrist,2019)

为什么担心影子银行？

影子银行存在严重期限错配问题，且不受存保险保障

上述特征导致影子银行非常容易而临自实现的债务展期危机（Rollover crisis），或者说挤兑问题（Gertler et.al,2015 2016,2019)



## 国内背景

近年来，中国影子银行规模同样出现了巨大幅度的增长；

仅考虑委托贷款、信托贷款与未贴现银行承兑汇票三项之和

的影子银行融资规模（Chen et.al,2018) 已从 2008 年第季度的 3.3 万亿増长至 2017 年第四季度的 27 万亿人民币

另一方面，相比于美国平行的影子银行与商业银行结构中国影子银行具有独特的结构。中国影子银行倾向于链式结构；

中国影子银行的独特结构主要表现为：影子银行是（中小）商业银行的影子。

大型商业银行与中小银行的非标投资差异较大，中小银行的其他投资是大型银行的四倍，且峰值规模接近 20 万亿；

由于商业银行与影子银行之间存在密切资金往来，而通道业务又将风险进一步传染至同业市场；一旦金融市场出现负面冲击（如违约），将容易引发债务展期问题，同时造成银行间市场的恐慌与混乱

2011 年与 2013 年的钱荒或许正源于此；



# 研究问题

从定量视角来看，中国影子银行的大繁荣是哪个部门的冲击造成的？

中国影子银行的迅速发展是否产生了某种足以引发金融危机的系统性风险？在观数据有限、极端危机事件具有极强非线性的前提下，我们又应该如何測算上述系统性风险？

如果真的存在这类风险，其成因是什么？爆发会造成多大的真实损失？影子银行的大繁荣与系统性风险的积聚存在怎样的关系？



# 本文工作

尝试构建一个刻画中国影子银行特殊结构（监管差异、风险差异）的 DSGE 模型。

运用贝叶斯估计与历史冲击分解考察影子银行大繁荣的成因。

结合 Gertler& Kiyotaki (2015)、Gertler et.al (2016、2019) 的债务展期危机模拟算法以及沖击推断结果来估计危机的条件转移“概率”，从而测算近十年来的系统性风险水平。

# 模型

## 模型结构要点

本文尝试构建的理论模型结构主要包括如下四点

- 传统商业银行与影子银行的密切资金往来，即银行的影子。
- 两类银行部门的监管差异，如安全贷款监管（Chen et.al,2018)。
- 影子银行与传统商业银行的业务风险差异，如影子银行投资高风险债务、传统商业银行投资低风险债务。
- 通过引入发行长期可违约债务的企业家，进而描述影子银行的期错配特征。

## 银行的危机模拟



- 本文所指的危机模拟类似于 Gertler& Kiyotaki (2015) 的挤兑模拟；

- 假想商业银行在期初会考虑一种特殊的“压力测试”，即是否对影子银行进行债务展期；

- 如果商业银行考虑不展期时，影子银行售资产造成高风险债务价格暴跌会导致影子银行浄资产小于零；

- 意味着挤兑的太阳黑子均衡（Sunspot equilibrium）是存在的；
