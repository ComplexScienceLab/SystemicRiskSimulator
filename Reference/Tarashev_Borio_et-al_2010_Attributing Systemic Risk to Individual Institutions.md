# Abstract

Tools that attribute system-wide risk to individual institutions are key elements of an operational macroprudential approach to financial stability. We propose to measure institutions’ systemic importance via an attribution methodology that is based on a game theoretic construct: the Shapley value. This methodology has a number of appealing features. First, owing to weak underlying assumptions, it can be used in conjunction with all popular risk measures. Second, it provides an exact allocation of risk that satisfies a concrete fairness criterion. Third, it accommodates easily uncertainty about model parameters and, more generally, uncertainty about the validity of the risk model.



将全系统风险归因于单个机构的工具是实现金融稳定的宏观审慎操作方法的关键要素。我们建议通过基于博弈论结构的归因方法来衡量机构的系统重要性：沙普利值。这种方法有许多吸引人的特点。首先，由于基础假设薄弱，它可以与所有流行的风险度量结合使用。其次，它提供了满足具体公平标准的准确风险分配。第三，它很容易适应模型参数的不确定性，更一般地说，它适应风险模型有效性的不确定性。

我们将此方法应用于许多程式化的银行系统和两个风险指标，即风险价值和预期短缺。这使我们能够研究具有系统重要性的不同驱动因素之间的相互作用：单个机构的规模、风险状况和共同风险因素敞口。我们还证明了一个定理，即在温和条件下，机构的系统重要性与其规模成比例地增加。这一发现的一个含义是，与机构规模成正比的政策干预会低估大公司相对于小公司的系统重要性。此外，我们展示了如何将 Shapley 价值归因方法用于宏观审慎资本要求的校准，这些要求在整个系统层面定义了目标，但在单个机构层面应用。最后，我们认为不同的政策工具需要使用一般沙普利价值方法的不同应用。
