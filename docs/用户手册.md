## 通用运行流程（Checklist）

在开始运行任何实验前，按下列顺序逐项检查并准备：

1. 确保已创建并激活 Python 虚拟环境，且安装依赖：
   - `python -m venv .venv`；Windows PowerShell 激活：`.\.venv\Scripts\Activate.ps1`。
   - `python -m pip install -r requirements.txt`。
2. 确认 `config.json`（项目根）中 `experiments` 字段包含要运行的实验（或明确指定 `--experiment-json` 或 `--set-config-folder`）。
3. 编辑实验配置目录下的 `set_config_variables.py`：至少确保相关路径字段正确（示例键名：`folderpath_config`、`folderpath_agents`、`folderpath_parameters`、`folderpath_models`）。
4. 运行并生成 agents 数据：进入 `folderpath_agents` 所指目录并运行 `python set_agents_variables.py`（会生成 `agents/*.pkl` 或其它需要的文件）。
5. 运行并生成 parameters 数据：进入 `folderpath_parameters` 所指目录并运行 `python set_parameters_variables.py`（会生成 `parameters.pkl` 等）。
6. 根据需要切换 `set_config_variables.py` 中的 `is_develope_mode`：
   - 开发/调试：`is_develope_mode = True`（在同一进程中运行，便于断点调试）；
   - 批量/生产：`is_develope_mode = False`（主进程会以子进程方式运行 `experiments_program.py`）。
7. 可选：若需要把资源复制到模拟器内部 `data/`，在 `set_config_variables.py` 里设置 `runtime_copy_resources_into_simulator_data = True`。开发阶段通常保持 False。
8. 运行统一入口：`python -m SystemicRiskSimulator --global-config config.json --experiment <name>` 或使用 `--experiment-json` / `--set-config-folder`。
9. 运行后检查输出目录（按 `set_config_variables.py` 中的 `folderpath_root_experiments` 与 `foldername_experiments` 生成），查看 `outputlog/`、`exp_output_data/` 等。

## 详细步骤说明（按项目中的组件）

- config.json（项目根）
  - 用于定义 runner 级别默认值与 experiments 清单（方便用 CLI 选择实验）。
  - 常见字段：`runner`（包含 `foldername_simulator`、`is_auto_confirmation` 等）、`default_experiment`、`experiments`（键为实验名，对应的对象至少包含 `folderpath_config`）。

- set_config_variables.py（实验级配置）
  - 真实决定实验运行细节：`folderpath_agents`、`folderpath_parameters`、`folderpath_models`、`is_develope_mode`、`list_idsExperiment_to_run`、可视化选项等。
  - 请保持其中的路径为相对项目根的路径（示例：`Samples/libraries/agents_library/agents_sample_IB2111`），不要写入本机绝对路径。

- agents 目录（由 `folderpath_agents` 指定）
  - 必须包含 `set_agents_variables.py`（用于生成/导出个体数据）与 `agents/` 子目录或生成后的 pkl 文件。

- parameters 目录（由 `folderpath_parameters` 指定）
  - 必须包含 `set_parameters_variables.py`（用于生成参数组合，导出 `parameters.pkl` 或类似输出）。

运行时合成配置流程（简述）
- CLI -> `main.py` 会：
  1. 读取 `config.json`（若使用 `--global-config`）并解析所选实验（或直接使用 `--experiment-json` 或 `--set-config-folder`）；
  2. 用 `build_simulator_config()` 合并 runner / experiment / override；
  3. 调用 `simulator(config)`：内部通过 `Tools.import_modules_from_package` 加载 `set_config_variables.py` 并把 `set_config_variables` 合并到全局变量 `sgv`；
  4. `Tools.set_experiments_folders()` 根据 `sgv` 设置输出目录并返回一系列 `folderpath_*`；
  5. 根据 `sgv` 的 `is_develope_mode` 决定是直接 import 运行 `experiments_program.main(sgv)` 还是以子进程方式运行。

## 运行实验（常用命令与示例，Windows PowerShell）

1. 使用全局 config.json + experiment 名（推荐）：

```powershell
python -m SystemicRiskSimulator --global-config config.json --experiment ib2111
```

2. 直接指定实验 JSON（绕过 global config）：

```powershell
python -m SystemicRiskSimulator --experiment-json Samples/exp_configs/exp_sample_IB2111.json
```

3. 兼容旧方式：直接指定 `set_config_variables.py` 所在文件夹：

```powershell
python -m SystemicRiskSimulator --set-config-folder Samples/libraries/configs_library/config_sample_IB2111
```

4. 在 IDE / 直接运行 `main.py`（等效命令）：

```powershell
python SystemicRiskSimulator/main.py --global-config config.json --experiment ib2111
```

额外：如果你只想预览合成后的配置（不执行耗时模拟），可以在 `set_config_variables.py` 中把 `schedule_operation['实验组模拟程序']` 暂置为 `False`，或通过 CLI 使用 `--override schedule_operation.实验组模拟程序=false`（注意 parse_overrides 支持的键值格式）。另外，`main.py` 在运行前会打印“合成后的最终 config（部分显示）”，可以先确认路径是否正确。

## 输出结构与常见问题诊断

常见输出文件夹（以 `sgv` 中字段命名）：
- `folderpath_experiments`：实验主文件夹（包含各次实验子目录）。
- `folderpath_experiments_output_config`：会保存 `set_config_variables.py` 的快照副本。
- `folderpath_experiments_output_agents`：会保存 agents 的快照（`agents/`、`set_agents_variables.py`、`logfile.log`）。
- `folderpath_experiments_output_parameters`：参数组合的快照。
- `folderpath_experiments_output_log`：包含 `outputlog.txt`（主日志）。
- `folderpath_experiments_output_data`：实验导出的最终数据（`exp_output_data/`）。

常见错误与排查建议：
- 找不到 agents 路径 / agents pkl：确认已在 `folderpath_agents` 指定目录运行 `python set_agents_variables.py`，并检查生成的文件（通常是 pkl 或 `agents/` 子文件夹）。
- 找不到 parameters.pkl：确认已在 `folderpath_parameters` 指定目录运行 `python set_parameters_variables.py`。
- 导入模型出错（ImportError）：检查 `folderpath_models` 指定的模型目录是否包含依赖（例如 `ComplexSystemLab` 等），必要时通过 `PYTHONPATH` 暂时加入模型库路径或安装依赖。
- 日志为空或没有生成数据：检查 `sgv['schedule_operation']` 中的相关开关（如 `实验组模拟程序`、`预处理实验结果程序` 等），以及 `is_collect`、`is_export_data_to_xlsx` 等导出设置。

调试小贴士：
- 为快速调试只跑一条实验：在 `set_config_variables.py` 中设置 `list_idsExperiment_to_run=[<单个 id>]`；或把 `list_idsExperiment_to_run` 设为较短列表。
- 降低运行代价：将 `test_max_num_of_turn` 设置为较小值，或缩小 `list_agents_yearName`、`num_bank` 等规模相关参数。
- 在开发过程中保持 `is_develope_mode=True`，这样会在主进程直接调用 `experiments_program.main(sgv)`，便于在 IDE 中断点调试。

## 示例：以 `IB2111` 为例的完整 Step-by-step（可复制的 PowerShell 命令）

说明：下面的示例按本仓库默认 Samples 布局（`Samples/libraries/...`）演示从准备到运行的完整流程。

1) 准备环境并激活（只需做一次）：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

2) 检查并（可选）编辑全局 `config.json`（项目根）确认默认实验名或在命令行指定实验：

```powershell
# 查看 config.json，确认 default_experiment 与 experiments 列表
type .\config.json
```

3) 查看并编辑实验配置（必要时确认 `folderpath_agents` / `folderpath_parameters`）：

```powershell
notepad Samples\libraries\configs_library\config_sample_IB2111\set_config_variables.py
```

关键点：确认文件中类似字段被正确设置（相对路径）：
- folderpath_agents=r"Samples/libraries/agents_library/agents_sample_IB2111"
- folderpath_parameters=r"Samples/libraries/parameters_library/parameters_sample_IB2111"
- folderpath_models=r"Samples/libraries/models_library/model_sample_IB2111"
- is_develope_mode=True  # 或 False（生产）

4) 在 agents 文件夹生成 agents 数据：

```powershell
Set-Location Samples\libraries\agents_library\agents_sample_IB2111
python set_agents_variables.py
# 运行后，检查是否生成了 agents/*.pkl 或 agents/ 子目录
Get-ChildItem -Recurse -File
```

5) 在 parameters 文件夹生成参数组合：

```powershell
Set-Location ..\..\parameters_library\parameters_sample_IB2111
python set_parameters_variables.py
# 运行后，检查是否生成 parameters.pkl 或其它导出文件
Get-ChildItem -Recurse -File
```

6) 回到项目根并以全局 config.json 运行实验（或使用 --set-config-folder）：

```powershell
Set-Location C:\Users\Ethan\CoreFiles\ProjectsFile\SystemicRiskSimulator
python -m SystemicRiskSimulator --global-config config.json --experiment ib2111
```

或（兼容旧方式，直接指定配置文件夹）：

```powershell
python -m SystemicRiskSimulator --set-config-folder Samples/libraries/configs_library/config_sample_IB2111
```

7) 运行时观察输出：
   - `main.py` 会打印合成后的部分 config，先确认 `folderpath_config`、`folderpath_agents`、`folderpath_parameters`、`folderpath_models` 等字段是否正确。
   - 运行完成后检查实验输出目录（通常位于 `data/sims_samples/<foldername_experiments>/...` 或 `sgv` 指定位置），关注：
	 - `outputlog/outputlog.txt`（主日志）
	 - `exp_output_data/`（导出结果）
	 - `output_config/set_config_variables.py`（配置信息快照）
	 - `output_agents/`（agents 快照）

8) 常见后续操作：
   - 可运行预处理/可视化脚本（由 `sgv['schedule_operation']` 决定是否自动运行）。
   - 若要重现结果，请把 `output_config/set_config_variables.py` 与 `output_agents`、`output_parameters` 保存为实验快照。
