# 建模思路、项目

### 思考  

- 主流经济学的问题：金融机构不应该仅仅是中介，而应该作为一个重要的体系考虑。  
- 费雪、明斯基：
    - 系统性风险一定不能避开债务问题，否则谈不上研究系统性风险





### 疑问与问题

- 是否考虑有限时间的折现？现有的折现大多考虑无穷时期的折现。
- 居民部门为什么要硬性分成借款型和储蓄型？  
    - 是否有投资型？  
    - 是否可以按照一定规则软性划分借款型和储蓄型？可以在一定条件下其属性强弱可以转换？  
        - 如果个人资产高于多少则具有储蓄和投资属性？  
        - 或者假设企业家或者银行家为储蓄型家庭？  
        - 假设如果银行家或企业家破产，则变成借款型居民？  
    - 是否可以每个居民都有借款和储蓄属性？  
- 如果假定消费品最终品厂商是充分竞争的，那么如何设定大厂商和小厂商的异质化？
- 如何在最终品生产商中考虑竞争力强弱？
- 考虑不同的最终品生产商$i$的不同的全要素生产率$A$  
- 考虑一个企业家对应一个企业，一个银行家对应一个银行  
- 在研究金融危机的时候，用均衡设定是否不太符合现实情况呢？
- 是否要考虑借贷的不同长短期，而不是单纯地设置为1期？
- 对于各部门来说，借贷款、存取款的期限在DSGE中，都只有1期。但是实际情况是有多期的。比如长短期存款，长短期贷款。是否要考虑借贷的不同长短期，而不是单纯地设置为1期，以体现银行的借短贷长的特性之一？  
- 是否考虑？
  - 如果考虑，那么就会内生化转换率之于居民之角色，而不是泊松过程。
    - 如果分析银行家的道德风险因素，有可能需要考虑银行家。不考虑的理由是：
        - 分析的重点应该放在银行方面，而不是企业部门。
